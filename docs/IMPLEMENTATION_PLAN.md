# Companion Kit 分阶段实施计划

## 总目标

做成一套轻量、易安装、易理解的虚拟陪伴能力：人格只是宿主原能力之外的表达层；固定人物照片是可选能力；四种宿主彼此独立。公共项目始终不包含私人 persona、照片、聊天、记忆、账号或凭据。

## 已冻结边界

- 支持 Codex、Claude、OpenClaw、Hermes 独立安装，不要求同时使用。
- Content Studio 只作为质量与思路参考，不搬运重型工作流或数据模型。
- 图片严格基线是官方 `gpt-image-2`、`high` 与参考图编辑；不能证明时关闭，不静默降级。
- Codex 原生模式与 API 严格模式必须清楚区分，不能包装成等价能力。
- 用户照片意图不等于付费授权；生成成功不等于投递成功。
- 只处理通用虚构成年人；当前阶段不导入任意外部照片或复刻真人。
- 关系是多维状态而非单一等级；长期关系不因闲置自动衰减，短期气氛有 TTL。

## 阶段 0–1：公共核心与关系契约（已完成）

- 干净独立仓库、四宿主安装器和本地初始化面板；
- 四套通用人格模板与版本化配置；
- 三维关系、短期气氛、确定性归约、事务、幂等、迁移与导出；
- 照片意图、纯 Kernel、Provider 路由与任务状态骨架；
- 工作树和全部 Git 对象隐私扫描。

## 阶段 2：Codex 图片闭环（本次实现）

### 原生便捷模式

- 无需 Companion Kit API Key；
- 使用 Codex 当前任务图片能力；
- 明确标为快速预览，不承诺 `high` 证明或跨任务固定身份；
- 结果只在当前任务显示，不外发 IM。

### API 严格模式

- 固定官方 Image API、`gpt-image-2`、`high`、PNG、单张输出；
- 新身份使用 `generations`，固定后使用唯一参考图 `edits`；
- `OPENAI_API_KEY` 只读当前进程环境；
- 十分钟、摘要绑定、单次消费的付费授权；
- 只保留一个候选槽和一张身份参考，不形成图库；
- PNG 实际解码校验与元数据清理；
- 当前任务短期成图、投递后删除、超时清理；
- Web 面板只显示能力状态，不接收 Key，不触发付费请求。

### 验收

- 无 Key 时状态清楚、`prepare` 在联网前失败；
- 测试传输证明请求固定官方端点、模型、画质和单次调用；
- 同一授权不能重复消费，原文或参考变化后失效；
- 原型确认后配置只保存一个不透明参考 ID；
- 日常照片使用参考编辑，投递确认后短期文件删除；
- 陪伴消息不展示内部提示、Router、Provider、轮询或本地路径；
- 全量测试、插件/Skill 校验、隐私扫描和独立终审通过。

## 阶段 3：事件型宿主适配（后续）

OpenClaw 与 Hermes 分别接入其真实图片 Provider 和当前入站会话媒体回复。每个适配器必须独立证明 Provider 能力、绑定入站目标、处理迟到结果和重复回调；不能复用私人宿主配置，也不能默认跨宿主共享状态。

## 阶段 4：Claude 与关系事件（后续）

- 在 Claude 明确具备当前任务图片工具和附件契约后再接入执行；
- 用固定样本测试从聊天提取低敏结构化关系事件；
- 普通问题解决与陪伴闲聊分流，关系只影响非任务聊天与允许的照片表达；
- Web 面板增加关系解释、重置和资产清理，不发展为内容生产平台。

## 回滚原则

- 每个宿主和图片模式都是独立适配器；失败时可以关闭该能力，不影响人格聊天与任务解决。
- 不迁移或改写现有私人宿主状态。
- 发现更高配置或数据库版本时停止写入，不猜测降级。
- 卸载程序默认不删除人格、关系或已确认参考图；数据删除必须单独确认。
