# 数据生命周期与删除语义

## 数据分区

Companion Kit 把数据分成互不混装的几类：

| 类别 | 示例 | 默认位置 | 是否进入公开项目 |
|---|---|---|---|
| 公开程序 | 核心代码、文档、通用模板 | 项目目录 | 是 |
| 人格配置 | 称呼、通用特征、形象文字、关系开关 | 独立用户配置目录 | 否 |
| 关系状态 | 三个维度、结构化事件、短期气氛 | 独立本地 SQLite | 否 |
| 参考与生成资产 | 用户确认的原型、候选图、成图 | 后续本地资产库 | 否 |
| Provider 凭据 | API key、宿主认证 | 宿主或系统凭据设施 | 否，项目也不保存 |
| 外部 Provider 副本 | 请求中上传的参考图与生成结果 | 第三方控制 | 不受本地删除控制 |

不保存完整聊天、联系人、工具参数、工具结果或完整图片提示词作为关系历史。结构化事件只保存事件类型、时间、增量、结果代码和不透明来源标识。

## 创建与更新

- 初始化只从通用模板创建新配置，不扫描现有宿主的人格、记忆、聊天或照片目录。
- 配置默认写出 `schema_version = 2`；版本 1 仍可读取，但不会在读取时原地改写。
- 关系状态数据库当前为 schema 2；打开 schema 1 时在单一事务中迁移宿主命名空间并保留状态，无法确认旧气氛来源时回滚并停止。发现更高版本时停止写入，不自动降级。
- SQLite 只支持本机普通文件系统。网络盘、共享盘和自动云同步目录不属于支持范围。
- 在支持 POSIX 权限的平台，关系目录收紧为仅当前用户访问，数据库文件为仅当前用户读写；路径经过用户可控符号链接时拒绝。
- 人格配置保存使用同目录私有锁文件协调多个本机进程；取得锁后重新校验版本，避免后写静默覆盖先写。

## 查看与导出

默认关系导出仅包含：

- 数据格式版本；
- `relationship_id`；
- 熟悉度、信任度、亲近度；
- 修订号和更新时间；
- 明确列出的排除项。

默认不导出事件明细、来源宿主、会话作用域、聊天文字、Provider 凭据、参考图路径或生成资产。未来若提供“完整诊断导出”，必须单独确认，并在生成前预览包含项。

## 重置、删除与卸载

- “重置关系”删除指定关系的状态、事件和当前气氛，不影响人格配置或其他关系。
- “清除本地关系数据”删除产品控制范围内的数据库主文件及其 WAL、SHM 和 rollback journal 边车文件。
- 人格配置、参考资产和生成资产应作为独立可选项删除，不能因为卸载 Skill 就默认删除用户内容。
- 卸载时应让用户选择“只卸载程序”或“同时清除本地数据”；当前安装器尚未提供自动卸载流程。

删除承诺只适用于产品控制范围内的当前本地文件，不等于安全擦除磁盘，也无法删除操作系统备份、文件系统快照、用户自行复制的导出包、宿主日志或 Provider 侧留存。若涉及高敏感内容，用户还需按操作系统和 Provider 的规则处理这些副本。

## 图片资产的后续要求

当前版本没有图片资产库。真实生图接入前必须满足：

- 导入时验证 MIME、像素、大小和解码结果，拒绝符号链接与伪装扩展名；
- 发给 Provider 前移除 EXIF、GPS 和不需要的色彩配置元数据；
- 临时文件使用随机名称和私有权限，任务结束后清理；
- 候选原型不自动进入聊天，只有用户确认的资产才能成为固定形象参考；
- 每张资产记录 `identity_version`，但不把真实路径写入公开配置或 Provider 提示词；
- 删除身份版本时同时处理缩略图、派生缓存和未完成任务。

## 日志与崩溃信息

默认日志允许记录版本、状态代码、匿名任务 ID、耗时和能力判断；禁止记录聊天正文、完整提示词、参考图内容或路径、联系人、凭据和授权头。崩溃报告若无法保证脱敏，应默认关闭或只保存在本机，并由用户主动导出。
