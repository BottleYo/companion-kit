# 数据生命周期与删除语义

## 数据分区

Companion Kit 把数据分成互不混装的几类：

| 类别 | 示例 | 默认位置 | 是否进入公开项目 |
|---|---|---|---|
| 公开程序 | 核心代码、文档、通用模板 | 项目目录 | 是 |
| 人格配置 | 称呼、通用特征、形象文字、关系开关 | 独立用户配置目录 | 否 |
| 关系状态 | 三个维度、结构化事件、短期气氛 | 独立本地 SQLite | 否 |
| 参考与生成资产 | 一个候选槽、唯一参考图、短期成图 | 当前宿主的 `private/images` | 否 |
| 单次图片授权 | OpenClaw / Hermes 严格调用的任务、提示与配置摘要 | 对应宿主的 `private/authorizations` | 否 |
| 事件图片作业 | 当前会话与事件摘要、阶段、不透明 ID | OpenClaw / Hermes 的 `private/event-jobs` | 否 |
| Provider 凭据 | API key、宿主认证 | 宿主或系统凭据设施 | 否，项目也不保存 |
| 外部 Provider 副本 | 请求中上传的参考图与生成结果 | 第三方控制 | 不受本地删除控制 |

不保存完整聊天、联系人、工具参数、工具结果或完整图片提示词作为关系历史。结构化事件只保存事件类型、时间、增量、结果代码和不透明来源标识。

## 创建与更新

- 初始化只从通用模板创建新配置，不扫描现有宿主的人格、记忆、聊天或照片目录。
- Codex 使用根级默认命名空间；OpenClaw、Hermes 与 Claude 使用 `hosts/<host>/` 独立命名空间。Web 面板和 CLI 不自动跨宿主复制配置、关系、授权或图片。
- 配置默认写出 `schema_version = 2`；版本 1 仍可读取，但不会在读取时原地改写。
- 关系状态数据库当前为 schema 2；打开 schema 1 时在单一事务中迁移宿主命名空间并保留状态，无法确认旧气氛来源时回滚并停止。发现更高版本时停止写入，不自动降级。
- SQLite 只支持本机普通文件系统。网络盘、共享盘和自动云同步目录不属于支持范围。
- 在支持 POSIX 权限的平台，关系目录收紧为仅当前用户访问，数据库文件为仅当前用户读写；路径经过用户可控符号链接时拒绝。
- 人格配置保存使用同目录私有锁文件协调多个本机进程；取得锁后重新校验版本，避免后写静默覆盖先写。
- OpenClaw / Hermes 图片授权只保存摘要，不保存任务原文或完整提示；默认十分钟过期，消费前先删除，避免进程自动重放付费请求。Codex 内置生图不创建这类授权。
- 事件作业按宿主、安装实例、当前会话和首次入站事件摘要去重；不保存联系人、chat ID、thread ID、聊天正文或绝对路径。默认保留 24 小时，过期后删除。
- 图片资产路径逐段拒绝符号链接；目录使用仅当前用户访问权限，清单与 PNG 使用仅当前用户读写权限。

## 查看与导出

默认关系导出仅包含：

- 数据格式版本；
- `relationship_id`；
- 熟悉度、信任度、亲近度；
- 修订号和更新时间；
- 明确列出的排除项。

默认不导出事件明细、来源宿主、会话作用域、聊天文字、Provider 凭据、参考图路径或生成资产。未来若提供“完整诊断导出”，必须单独确认，并在生成前预览包含项。

## 重置、删除与卸载

- “重置关系”删除指定关系的状态、事件和当前气氛，不影响人格配置或其他关系。
- “清除本地关系数据”删除产品控制范围内的数据库主文件及其 WAL、SHM 和 rollback journal 边车文件。
- 人格配置、参考资产和生成资产应作为独立可选项删除，不能因为卸载 Skill 就默认删除用户内容。
- 卸载时应让用户选择“只卸载程序”或“同时清除本地数据”；当前安装器尚未提供自动卸载流程。

删除承诺只适用于产品控制范围内的当前本地文件，不等于安全擦除磁盘，也无法删除操作系统备份、文件系统快照、用户自行复制的导出包、宿主日志或 Provider 侧留存。若涉及高敏感内容，用户还需按操作系统和 Provider 的规则处理这些副本。

## 图片资产

`0.6.0-dev.1` 的 OpenClaw 与 Hermes 严格模式使用同一最小资产库实现。Codex 的跨任务参考图桥接完成后会复用同一套 PNG 校验与私有参考槽，但不会复用 API 授权和执行器。资产库不是图库：

- 只接受 Companion Kit 当前流程从宿主生图结果取得的 PNG，不提供任意真人照片导入；
- 严格校验签名、分块长度、CRC、像素格式、像素数量和实际解码大小；
- 保存前重写为只含 `IHDR`、`IDAT`、`IEND` 的 PNG，移除文本、EXIF、GPS 和其他附加元数据；
- 每个 `profile_id + identity_version` 只有一个候选槽和一张已确认参考图；新候选替换旧候选，不保留历史；
- 原型交给事件型宿主前会生成一个路径唯一的短期快照，避免另一会话覆盖候选槽时改变已交付内容；该快照收到明确回执后删除，否则按一小时上限清理；
- 参考清单只保存不透明 ID、内容哈希、MIME、尺寸、来源和时间，不保存提示词、聊天、响应正文或真实路径；
- 人格配置只保存一条不透明 `reference_id`；只有用户确认候选后才写入；
- 日常成图保存在当前任务或会话绑定的短期目录，明确附件回执后立即删除；没有回执的 `delivery_unknown` 成图不自动重投，在后续启动时按一小时上限清理；
- 候选与参考图不会因为卸载 Skill 自动删除，避免程序卸载误删用户已确认身份。

生成图写入与人格引用更新跨两个独立文件边界，无法形成单一事务。执行顺序先写资产、再更新配置；若极小竞争窗口发生配置冲突，资产会保持为未被配置引用的孤儿，绝不会自动启用。后续清理工具需要显式列出并让用户确认。

## 日志与崩溃信息

默认日志允许记录版本、状态代码、匿名任务 ID、耗时和能力判断；禁止记录聊天正文、完整提示词、参考图内容或路径、联系人、凭据和授权头。崩溃报告若无法保证脱敏，应默认关闭或只保存在本机，并由用户主动导出。
